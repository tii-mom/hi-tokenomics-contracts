HI 主网部署前合约审查说明

本页用非技术语言说明当前 7 个合约的用途、100 亿 HI 的发行流向、代币发行后能否正常转账、各存币合约如何转出代币，以及主网前安全检查结论。

审查结论

结论：未发现需要主网前修改合约代码的阻塞问题。

本次复查重点覆盖代币正常转账、增发、黑白名单、冻结、暂停、税费、升级、自毁、余额异常操作、业务合约存币转出机制。当前本地门禁全部通过，测试结果为 69 passed in 7 files。

项目结论说明

7 个合约分别负责什么

JettonMinter负责创建 HI、记录总供应、计算用户 Jetton Wallet 地址。部署完成并 drop admin 后不能再增发或升级。
JettonWallet每个持币地址对应一个钱包合约。用户转账 HI 时，实际由自己的 Jetton Wallet 执行。
GrowthEngine增长引擎，承载公开销售。用户买入后按价格等级领取 HI。
PriceOracle价格等级确认合约。管理员上报价格，等待主网 86400 秒后确认等级。
TeamVestingVault团队锁仓合约。达到团队 USDT 价格等级后，释放给团队钱包。
CampaignWinnerVault500万 HI winner 合约。80 名 winner 逐步领取奖励。
MerkleRewardVault生态和红包领取合约。后端生成 Merkle root，用户用 proof 自助领取。

存有 HI 的合约如何转出

存币位置正常转出方式异常/迁移转出方式不能被转走的部分
GrowthEngine 用户购买后 level 0 立即领取 5%；level 1-9 每级 10%；level 10 最后 5%。用户忘记领取也不会过期，可后续一次性领取已解锁部分。 销售永久关闭后，未售 HI 和 missed HI 可 sweep 到项目基金钱包。未承诺 HI 可由 migration wallet 迁移到 admin allowlist 目标合约。 用户已购买但未领取的 HI 不能被 sweep 或迁移。
TeamVestingVault 达到 0.1、0.5、1、5 USDT 团队价格等级后，每级释放 300,000,000 HI 到团队钱包。 保留 migration target 选择语义，但 uncommitted=0，实际没有可迁移团队 HI。 全部 1,200,000,000 HI 都承诺给团队价格释放计划，不能被迁走。
CampaignWinnerVault 已注册 winner 自己 claim。每名 5,000,000 HI，规则与 GrowthEngine 一致：level 0 为 5%，level 1-9 为 10%，level 10 为 5%。 未注册、未承诺的剩余额度可由 migration wallet 迁移到 admin allowlist 目标合约。 已注册 winner 的 5,000,000 HI 承诺额度不能被迁走。
MerkleRewardVault 用户提交 Merkle proof 自助领取。每个 batchId + wallet 只能领一次，支持 requiredGrowthLevel。 未创建 batch、未承诺的剩余额度可由 migration wallet 迁移到 admin allowlist 目标合约。 已创建 batch 的 totalHi 属于 committed，不可作为未承诺余额迁走。
项目基金 / 流动性 / 投资钱包 普通钱包自行转账。 不走业务合约 migration。 由钱包私钥或多签控制，合约层没有额外限制。

注意：migration 是为“合约出现问题时把未承诺 HI 转到新合约”准备的救援路径，不是普通提款功能。它不能转走用户已购买、winner 已注册、Merkle batch 已发布、团队已承诺的 HI。

价格 oracle 如何工作

当前主网版本不是自动抓交易所价格。价格由 oracle admin 上报，合约只根据上报价格和等待时间确认等级。

项目规则
Growth level0 到 10 级，只能一级一级递增，不能跳级、不能回退。
Team level0 到 4 级，只能一级一级递增，不能跳级、不能回退。
主网确认延迟86400 秒，即 24 小时。
谁能上报价格只有 oracle admin。
谁能确认成熟等级候选等级成熟后，任何 keeper 都可以触发 confirm；但必须已经由 oracle admin 上报候选价格并等待满 24 小时。

仍需接受的权限边界

下面不是本次发现的新漏洞，而是主网运行必须理解的管理边界。

权限谁控制能做什么不能做什么
admin / deployer / reward admin主网 admin 多签或单签部署、配置业务合约 Jetton Wallet、管理 GrowthEngine、注册 winner、创建 Merkle batch、管理 migration allowlist。在 minter admin drop 后不能增发 HI，不能强制转走用户钱包里的 HI。
oracle admin独立 oracle admin 地址上报 growth/team USDT 价格候选等级。不能直接转走 HI，不能跳级确认，不能回退等级。
migration wallet 1 / 2两个迁移钱包选择 admin allowlist 中的目标合约，并迁移未承诺 HI。不能迁移已购买未领、已注册 winner、已发布 batch、团队已承诺的 HI。

如果你希望进一步降低管理权限风险，可以考虑未来版本增加 timelock、code-hash 校验或把部分配置改成部署后不可修改。但这会改变合约 hash，需要重新测试、重新 testnet、重新审计。当前主网前不建议临时改动，除非你决定重新走一轮完整流程。
